# Prompt bộ icon Long Tượng

Tạo bằng công cụ `image_gen` tích hợp, một lần gọi cho mỗi icon; nền trong suốt. Xuất PNG RGBA 128×128 (trang bị/chức năng), 64×64 (tiền tệ), thêm lề trong suốt, giữ tỷ lệ ảnh gốc.

## Prompt chung

Thay `SUBJECT` bằng mô tả tương ứng trong bảng.

```text
Use case: stylized-concept. Asset type: production PNG UI icon for the Long Tuong Three Kingdoms fantasy RPG. Create exactly ONE isolated icon: SUBJECT. Style: polished hand-painted 2.5D mobile RPG inventory art, bold readable silhouette at 48px, clean dark contour, restrained detailed metallic highlights, antique gold accents with jade, red silk and blue steel. Consistent soft upper-left lighting. Square canvas, centered entire object occupying 80 percent of canvas, generous clean transparent margins on all sides. Genuine transparent alpha background, no ground, no cast shadow, no backdrop, no tile, no border, no button, no lettering, no watermark, no extra objects. Do not create a sheet or grid.
```
